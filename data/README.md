# Data Directory

Place raw and processed data files here:
- `tweets_tech.csv` — Tech sector tweets (Twitter API v2)
- `tweets_pharma.csv` — Pharma sector tweets
- `tweets_energy.csv` — Energy sector tweets
- `stock_prices.csv` — Daily OHLCV data (Yahoo Finance / yfinance)
- `daily_sentiment.csv` — Aggregated daily VADER scores
- `volatility.csv` — Computed realized volatility per sector
